# 여기부터 보세요 (받으신 분께)

업무 자동화 프로그램을 **대화만으로** 만들어주는 도구를 받으셨습니다.
처음이셔도 괜찮습니다. 아래 순서만 따라오세요.

---

## 3분 요약

1. 이 폴더를 원하는 위치에 두세요. (예: `C:\AutoProjects\my-automation`)
   - 폴더명은 영문 + 하이픈 권장 (한글/공백 피하기)
2. 컴퓨터에 **Node.js** 와 **Python** 이 설치되어 있어야 합니다.
   - 안 되어 있으면 `QUICK_START.md` 의 "2. 필요한 도구 설치" 를 먼저 보세요.
3. CLI AI 도구(예: **Claude Code**)를 설치하고 로그인하세요.
   - 방법은 `QUICK_START.md` 의 "3. CLI AI 도구 선택 & 설치" 참고.
4. 이 폴더에서 터미널을 열고 AI를 켠 뒤, 아래 **한 줄**을 입력하세요.

```
AUTOMATION_BUILDER_PRD.md 파일을 읽고 그대로 시작해줘
```

그 다음부터는 AI가 묻는 것에 답만 하시면 됩니다.

---

## 이 폴더에 뭐가 들어 있나요?

| 파일 | 용도 |
|------|------|
| **START_HERE.md** | 지금 이 파일 |
| **QUICK_START.md** | 처음 사용자를 위한 상세 셋업/사용 안내 (꼭 읽기) |
| **AUTOMATION_BUILDER_PRD.md** | AI에게 주는 지침서. 당신이 읽을 필요는 없지만 폴더에 꼭 있어야 함 |
| **README.md** | 이 도구가 무엇인지 소개 |
| **examples/** | 다른 사람이 만든 자동화 사례 (참고용) |

---

## 당신이 할 일은 4가지뿐

1. 자동화할 화면을 캡쳐해서 폴더에 넣기
2. AI 질문에 답하기
3. 결과 확인하기
4. "다음", "다시 해줘", "에러 났어" 같은 자연어 명령

명령어 입력, 코드 작성, 설치, 빌드는 **AI가 다 합니다.**

---

## 막히면?

- 자세한 안내와 자주 묻는 질문은 **`QUICK_START.md`** 에 다 있습니다.
- 그래도 막히면 AI에게 그냥 "이거 안 돼" / "처음이라 모르겠어" 라고 말하세요.

즐거운 자동화 되세요.
