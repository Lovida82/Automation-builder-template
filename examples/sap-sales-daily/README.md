# 사례 1 — SAP 웹포털 일일 판매실적 다운로드 자동화

> 이 사례는 본 템플릿의 동작을 보여주기 위한 **참고용 샘플**입니다.
> 실제 회사/시스템과 무관하며, 모든 데이터(URL, 계정, 거래처명, 금액)는 더미입니다.

---

## 업무 설명

매일 아침 SAP 웹포털에 로그인해서 **전일 판매실적**을 조회하고, 엑셀로 다운로드한 뒤
정해진 폴더에 `판매실적_YYYYMMDD.xlsx` 형식으로 정리하는 업무.

손으로 하면 매일 같은 클릭을 20여 번 반복해야 했고, 가끔 날짜를 잘못 넣거나
다운로드 파일 정리를 빼먹는 실수가 있었습니다.

## 사용 환경

| 항목 | 내용 |
|------|------|
| 자동화 경로 | 웹포털 (Playwright) |
| 사용한 CLI AI 도구 | Claude Code |
| 만드는 데 걸린 시간 | 약 2시간 (대화 + 캡쳐 포함) |
| 만든 사람의 개발 경험 | 비개발자 (엑셀 함수 정도는 다룸) |
| 최종 산출물 | `판매실적자동화.exe` (단일 실행파일, 약 70MB) |

## 자동화 흐름

본 템플릿 PRD의 단계별 사이클대로 5개 스텝으로 나눠 개발했습니다.

| # | 스텝 | 동작 | 비고 |
|---|------|------|------|
| 1 | 로그인 | 포털 URL 접속 → ID/PW 입력 → 로그인 | 자격증명은 keyring 저장 |
| 2 | 메뉴 진입 | 메인에서 '판매현황' 메뉴 클릭 | 조회 화면 진입 |
| 3 | 조회 | 시작일/종료일에 '어제' 자동 입력 → 조회 | 결과 테이블 로딩 대기 |
| 4 | 다운로드 | '엑셀 다운로드' 버튼 클릭 | 다운로드 완료 대기 |
| 5 | 후처리 | 다운로드 파일을 output/로 이동 + 이름 변경 | `판매실적_YYYYMMDD.xlsx` |

## 효과

| 항목 | 자동화 전 | 자동화 후 |
|------|-----------|-----------|
| 소요 시간 | 매일 약 15분 | 클릭 1번, 30초 미만 |
| 실수 | 가끔 날짜 오입력/정리 누락 | 없음 (날짜 자동 계산) |
| 추가 효과 | - | 출근 직후 다른 업무에 집중 가능 |

## 재사용 팁

- **"어제 날짜"처럼 매번 바뀌는 값**은 화면 캡쳐에 그날 날짜가 찍혀 있어도 괜찮습니다.
  Claude에게 "이 날짜는 매일 어제로 바뀐다"고 말해주면 자동 계산하도록 코드를 짜줍니다.
- **조회 결과 로딩이 느릴 때**가 가장 흔한 실패 지점입니다. "결과가 나오기까지 보통 몇 초
  걸리느냐"는 질문에 넉넉히(예: 평소 7초면 30초) 답해두면 안정적입니다.
- 비슷한 "정기 다운로드" 업무(주간 보고서, 월간 정산 등)는 이 사례를 거의 그대로 응용할 수 있습니다.
