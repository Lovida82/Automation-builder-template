# 자동화 사례 모음

이 템플릿으로 만들어진 실제 자동화 사례들을 모아놓은 곳입니다.

다른 사람의 사례를 보면 본인 업무에 어떻게 적용할 수 있을지 아이디어를 얻을 수 있습니다.

## 사례 목록

> 아직 등록된 사례가 없습니다.
> 첫 번째 사례를 공유해 주세요! → [자동화 공유 Issue](../../issues/new?template=automation_share.md)

### 사례 작성 시 권장 형식

각 사례는 별도 폴더로 추가됩니다. 예시:

```
examples/
├── README.md                          ← 이 파일
├── sap-sales-daily/                   ← 사례 1
│   ├── README.md                      ← 사례 설명
│   ├── PRD-snippet.md                 ← 적용 시 추가한 PRD 부분 (선택)
│   └── lessons-learned.md             ← 시행착오 (선택)
└── portal-report-weekly/              ← 사례 2
    └── ...
```

### 각 사례 README에 포함하면 좋은 내용

- **업무 설명**: 어떤 일을 자동화했는가 (1~2줄)
- **사용 경로**: 웹 / SAP GUI
- **개발 환경**: CLI 도구, 소요 시간, 만든 사람의 개발 경험 수준
- **시행착오**: 막혔던 부분, 해결 방법
- **결과**: 자동화 전 후 시간 비교, 도움 된 점
- **재사용 팁**: 비슷한 업무 만드는 사람에게 한 마디

**[주의] 반드시 민감 정보(실제 거래처명, 금액, 사내 시스템 IP 등)는 더미 데이터로 변환**

## 자주 만들어지는 자동화 유형

이 템플릿이 가장 잘 맞는 업무 유형들:

| 유형 | 예시 | 난이도 |
|------|------|--------|
| 정기 다운로드 | 사내 포털/SAP에서 매일/매주 보고서 다운로드 | 하 |
| 데이터 수집 | 여러 페이지/거래처 사이트 데이터 모으기 | 중 |
| 일괄 업로드 | Excel 데이터를 시스템에 일괄 입력 | 중 |
| 데이터 변환 | 다운로드 받은 파일 가공해서 다른 형식으로 | 하 |
| 알림/리포트 생성 | 데이터 수집 → 메일/슬랙 자동 발송 | 중 |
| 모니터링 | 가격/재고/상태 주기적 확인 후 알림 | 상 |

## 본인 사례 공유하기

1. 본인 자동화가 잘 동작하는 것 확인
2. 민감 정보 제거/더미화
3. [Automation Share Issue](../../issues/new?template=automation_share.md) 등록
4. 또는 직접 Pull Request로 `examples/your-case-name/` 폴더 추가

여러분의 사례가 다음 사람에게 큰 도움이 됩니다.
